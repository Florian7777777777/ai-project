# AI Project - Image Classification (Simple CNN)

## 📌 Project Description
This project is a simple deep learning model based on Convolutional Neural Networks (CNN) using PyTorch.  
It demonstrates the full pipeline of training, saving, and predicting using an AI model.

## ⚙️ Tech Stack
- Python
- PyTorch
- CNN (Convolutional Neural Network)

## 📂 Project Structure
- `train.py` → Train the model
- `model.py` → Define CNN architecture
- `predict.py` → Make predictions
- `app.py` → Simple application interface

## 🚀 Features
- Build a CNN model from scratch
- Train on generated data
- Save trained model
- Run predictions

## 📌 Future Improvements
- Use real datasets
- Improve model accuracy
- Deploy as a web application
